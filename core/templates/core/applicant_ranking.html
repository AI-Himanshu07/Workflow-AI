How Candidate Ranking Works

Candidates are arranged using the following priority:

  1. Completed assessment candidates appear before candidates who have not attempted it.
  2. Higher assessment percentages receive higher positions.
  3. CGPA is used when assessment performance is equal.
  4. More recent applications are placed first when the previous criteria are equal.

This ranking supports recruitment decisions. The company remains responsible for reviewing profiles and making final hiring decisions.
